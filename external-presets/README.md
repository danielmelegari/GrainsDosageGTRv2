# External psy preset banks

Two separate ZIPs, 12 authored presets each. Not bundled into the plugin or installer.

- Parvati Inspired — Forest Rituals: woody grains, vocal/formant movement, dark rhythmic patterns and two dedicated wet-space patches.
- Psy Hi-Tech — Laser Circuits: timed pitch sweeps, metallic comb tones, programmed repeats, reverse cuts and a fixed bitcrushed patch.

Each ZIP includes installation instructions, a preset-by-preset source/use guide and automated audio validation results. Every enabled module mix is 100%.

Authoring source: `tools/export_external_psy_banks.cpp`. Build/run this offline exporter only; no plugin workflow is required.
