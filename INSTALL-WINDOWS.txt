GrainsDosage 0.13.22 - Windows 10/11 x64, three-page interface

1. Close Cubase and other audio hosts.
2. Run the Windows x64 ThreePage Setup executable.
3. The 14-Day-Trial edition starts automatically on first use. No license
   code is required. Purchased licenses use the separate Licensed edition.
4. Start Cubase, rescan VST3 plugins if needed, and insert GrainsDosage as an
   audio effect. Verify version 0.13.22 in Cubase's plugin information.

Installed plugin: C:\Program Files\Common Files\VST3\GrainsDosage.vst3
The complete folder is the plugin bundle. Do not move just its internal binary.

Read GrainsDosage User Manual in the Start menu for all three pages, every
Reslice control, modulation, Morph, presets, CPU advice and troubleshooting.

The offline Trial runs for 14 consecutive days from first use, including time
with the DAW closed. The header shows the days remaining. At expiry, output fades
to silence and wet processing stops. See AUTOMATIC-TRIAL.txt for details.
