GrainsDosage 0.13.1 - Windows 10/11 x64, three-page interface

1. Close Cubase and other audio hosts.
2. Run the Windows x64 ThreePage Setup executable.
3. For the 14-Day-Trial edition, open GrainsDosage Trial Registration in the
   Start menu and install the publisher-signed license for your machine.
4. Start Cubase, rescan VST3 plugins if needed, and insert GrainsDosage as an
   audio effect. Verify version 0.13.1 in Cubase's plugin information.

Installed plugin: C:\Program Files\Common Files\VST3\GrainsDosage.vst3
The complete folder is the plugin bundle. Do not move just its internal binary.

Read GrainsDosage User Manual in the Start menu for all three pages, every
Reslice control, modulation, Morph, presets, CPU advice and troubleshooting.

The offline trial runs from its signed start until exactly 14 calendar days
later. There is no one-hour session timeout. Registration shows its dates.
An unregistered, not-yet-active or expired trial produces no audio.
