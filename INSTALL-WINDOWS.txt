GrainsDosage 0.13.0 - Windows 10/11 x64

1. Salva il progetto e chiudi Cubase o la tua DAW.
2. Avvia GrainsDosage-0.13.0-Windows10-x64-Setup.exe.
3. Il plugin completo viene installato in:
   C:\Program Files\Common Files\VST3\GrainsDosage.vst3
4. Riapri la DAW e avvia la scansione dei plugin VST3.

Richiede una DAW Windows x64 con supporto VST3.
Il file Mac .vst3 non funziona su Windows.
L'installer richiede privilegi amministrativi. Non include firma Authenticode.

Per l'installazione manuale, estrai GrainsDosage-Windows10-x64.zip e copia
l'intera cartella GrainsDosage.vst3 nel percorso sopra. Non estrarre soltanto
il file interno Contents\x86_64-win\GrainsDosage.vst3.
Non installare contemporaneamente copie dello stesso plugin in altri percorsi.

Preset: menu Presets -> Open Preset Folder.
Cartella: %APPDATA%\GrainsDosage\Presets
Il plugin crea i 30 preset di fabbrica al primo utilizzo del menu preset.

Disinstallazione: Impostazioni Windows -> App -> GrainsDosage VST3.
I preset dell'utente restano nella cartella AppData.
