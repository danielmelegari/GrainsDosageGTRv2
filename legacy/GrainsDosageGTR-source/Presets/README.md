# Factory presets — GrainsDosage 0.9.0

1. Clean Grains — neutral granular starting point.
2. Forest Drift — slower grains, alternating pan and pitch movement.
3. Psy Scatter — short dense grains, random pan and stepped pitch.
4. Octave Dust — octave-up grains with an ambient tail.
5. Reverse Glitch — reversed slices before the granular stage.
6. Micro Stutter — short automatic repeats.
7. Triplet Chops — triplet repeats with intermittent glitch.
8. Half Time Mist — half-speed wet processing and reverb.
9. Space Bloom — sparse sends and a long tail.
10. Acid Motion — resonant driven filter with LFO cutoff modulation.

The plugin installs missing copies when opening its preset menu. It does not
replace existing files. Save custom presets into the same folder to list them.
Files contain settings, not audio. Use your own source and adjust Dry/Wet/Amount.
