GrainsDosage — offline trial and permanent activation

In the plugin, click ACTIVATE. Copy the complete Machine ID and send it to the
publisher. Trial activation does not require a License ID. Paste the FULL text
from GrainsDosage-Trial-Key.txt or GrainsDosage-Permanent-Key.txt, then click
Activate. Processing is enabled without restarting the DAW.

The header shows TRIAL ACTIVE and remaining calendar days, TRIAL EXPIRED,
or LICENSED. A trial lasts 14 days from the signed issuance date. It has no
one-hour session limit. Expiry fades the effect to dry over 20 ms without
interrupting the DAW or altering saved settings.

The optional Start-menu Registration tool can export a JSON request (Yes)
or install the publisher TXT / legacy .license file (No). Reload the plugin
after using that external tool. Dates displayed by Registration are UTC.

Activation is offline and specific to the registered machine. Do not change
the system clock or edit the signed code. The private signing key stays with
the publisher and is never needed on the customer's computer.
